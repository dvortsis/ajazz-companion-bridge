# Glossary

Terms used in this guide, A to Z. Each chapter links a term here the first time it uses it.

## Appdata

The folder on an Unraid or Docker server that holds an app's settings and logs across updates.

## Companion

Bitfocus Companion, the button-control software that renders button graphics and runs actions when you press a control.

## Container

A packaged, running copy of an app. An update replaces it, so only mapped folders keep their files.

## Hidraw

A Linux `/dev/hidrawN` device file that gives a program direct access to one USB human-interface device.

## Host mode

A Docker network setting where the container shares the server's network address instead of using an isolated network.

## Port forwarding

A router rule that sends traffic from the internet to one device on your home network.

## Satellite API

The network feature in Bitfocus Companion (TCP port `16622`) that lets external programs register a button surface.

## Surface

Bitfocus Companion's name for any connected keypad, touch strip or dial controller that displays and triggers buttons.

## System tray

The row of small status icons near the clock on Windows, or the menu bar at the top of macOS.

## Touch strip

The wide LCD bar above the four dials on the Ajazz AKP05E, divided into four touch zones and left/right swipes.

## Udev rules

Linux permission files in `/etc/udev/rules.d/` that let a non-root user open a USB device without administrator rights.

## VPN

A private, encrypted connection to your home network from outside, such as WireGuard or Tailscale.
